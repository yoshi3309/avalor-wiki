# Public Canon Release Log

**Purpose:** Lightweight index of **new** Keeper-approved, player-visible lore batches published after adoption of the [Canon Intake & Publication Playbook](CANON_INTAKE_PLAYBOOK.md). Historical corrections already recorded in [Public Canon Editorial Overrides](PUBLIC_CANON_OVERRIDES.md) remain in that ledger and are not copied here.

Each new release gets one row. Include only material already cleared for public wiki publication. **Do not** include draft secrets, future-story titles, unpublished identities, private source texts, unapproved hypotheses or details that could spoil a campaign. Batch dates are editorial calendar dates, not years in Avalor.
