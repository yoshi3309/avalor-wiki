# Artwork Production — Next Ten Confirmed Wiki Subjects

**Status (November 10, 2026):** All ten locations from the prior wave now have image references in their published Markdown source files and the corresponding uploads exist. The location Gallery auto-indexing introduced in November incorporates assigned landscape images after a successful deployment. The four original Renada/Black Tower/Heaven's Heart/Stanleyville curated location exhibits remain intact.

This proposed wave includes only public, existing `Kingdoms & Places` articles that **currently have no assigned `image:`**. No new lore or hidden material is supplied by the prompts. Illustrations are interpretive concept art rather than photographic records. Default: realistic painterly high fantasy, 16:9 landscape, around 1920x1080, no baked-in typography, and captions reflecting an illustrated interpretation.

Avoid inventing royal coats of arms, identifiable rulers, exact floor plans, named interiors, text, ceremonies or supernatural effects.

## Publication workflow

1. Generate and approve one image for each subject using its existing public article as the factual brief. Take care when images imply historical dates, royal insignia, building layouts or geographic boundaries.
2. Upload via Pages CMS to the matching published encyclopedia article and set its `image:` to the new `assets/uploads/` path. Use descriptive alt text and a truthful, source-grounded caption.
3. The builder adds published `Kingdoms & Places` article illustrations to the Locations Gallery automatically, unless a curated Gallery exhibit already represents that subject and image.
4. Confirm the new GitHub Actions run reaches `success` before treating the change as live. For intermittent editor fetch errors, inspect GitHub history before retrying an upload.
5. Only when needed, create a curated Gallery exhibit for a special alternative version, with confirmed article links. Avoid duplication.

No website-facing article text should be changed based solely on details produced by an image model.
